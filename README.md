## Features
- **Mobile-First Bento Layout**: Dynamic rhythmic layout with dual aspect ratios (16:9 cinematic landscape & 4:5 vertical reels).
- **Zero-Lag Inline Video Previews**: Intelligent IntersectionObserver engine with seamless scroll playback, buffering indicators, and progress bars.
- **Interactive Project Scope & Cost Estimator**: Transparent dynamic quote builder in Indian Rupees (₹ INR) with one-click WhatsApp export.
- **Floating Mobile Glass Dock**: Quick ergonomic navigation dock with safe-area spacing and tap-to-chat triggers.
- **Full-Screen 4K Showreel & Deep-Dive Case Studies**: Interactive modals with comprehensive business metrics, production specs, and client endorsements.
